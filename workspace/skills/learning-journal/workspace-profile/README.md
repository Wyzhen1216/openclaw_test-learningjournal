# Learning Journal Workspace Profile

这个目录保存 learning-journal 的 workspace 配套身份文件。

## Included files

- `AGENTS.md`
- `SOUL.md`
- `IDENTITY.md`
- `TOOLS.md`

## Usage

在 `skills/learning-journal/` 下执行：

```bash
npm run sync:profile
```

脚本会将上述文件同步到 **workspace 根目录** 与 **本技能根目录**（`skills/learning-journal/`），避免在多处手改同一份规范。

## Maintenance

如果你希望调整人格或行为规范，优先修改这里的文件，再执行同步命令。
